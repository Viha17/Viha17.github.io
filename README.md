# Vihanga Anush · Portfolio

Personal portfolio, live at **https://viha17.github.io**.

Plain HTML, CSS and JavaScript with one canvas particle swarm. No build step: open `index.html`, or serve the folder with any static server.

Every push to `main` deploys through GitHub Actions (`.github/workflows/pages.yml`).

Fonts: General Sans (Fontshare, ITF Free Font License) and JetBrains Mono (SIL OFL), self-hosted in `fonts/`.
