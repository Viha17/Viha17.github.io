EcoShift

Final-year project · 2026

A React UI that lightens itself before it stutters.

EcoShift reads how hard the visitor's device is working, using an ONNX model that runs in the browser, and steps the interface down when pressure rises. I demo it on AegisNet, a cloud DDoS-monitoring dashboard, and I built every stage of the pipeline behind it.
